# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
[Play the Game](https://adityajha108.github.io/Tic-Tac-Toe/)

## ✨ Features
- Two-player gameplay
- Winner detection
- Draw detection
- Restart game functionality
- Interactive user interface
- Responsive design (if supported by the current implementation)

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
- `index.html` — Game structure
- `style.css` — Styling and layout
- `app.js` — Game logic

## ▶️ Run Locally
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
